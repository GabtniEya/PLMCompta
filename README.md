# PLMCompta

Application web PLM Ressource : vitrine de services, panier, commandes, factures et espace d'administration.

## Lancer le projet

```powershell
npm install
npm run dev
```

Ouvrez ensuite `http://localhost:5173`.

## Important

Créez un fichier `.env` local avec les variables Supabase. Ce fichier n'est pas versionné.
